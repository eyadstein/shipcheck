# Roadmap

| Milestone | Theme | Idea |
|---|---|---|
| 7 | Disclosure ledger | Compare what the code does with what the privacy policy says |
| 8 | Rule gym | Attack the rules with generated evasion variants and grade how robust each one is |
| 9 | Originality index | Measure how much of a design is framework defaults, and run the scanner in the browser |
| 10 | Fix planner | Find the smallest set of fixes that reaches a target score, and apply the simple ones |
| 11 | Finding history | Find the commit that introduced each finding and how long it has been open |
| 12 | Data atlas | Draft a privacy policy from the ledger and map data flows in the dashboard |
